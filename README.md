# Introductory
Hi! it seems your interested into asset bundle making!, this is for just that
# What to do
the file BuildAssetBundle.cs is supposted to go into your Editor folder (make one if you didnt yet)
To make a asset bundle you MUST put the thing you want to export(it must be in your assets folder as a prefab) then you go to the bottom right while selected on the prefab, and click the tab down and make a new thing (click on new) and name it (make it like prefab_example or just example_example replacing spaces with "_")
then it should export to the streaming assets folder!
