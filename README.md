# What to do
the file BuildAssetBundle.cs is supposted to go into your Editor folder INSIDE your project assets (make one if you didnt yet)
To make a asset bundle you MUST put the thing you want to export(it must be in your assets folder as a prefab) then you go to the bottom right while selected
on the prefab, and click the tab down and make a new thing (click on new) and name it (make it like prefab_example or just example_example replacing spaces with "_")
